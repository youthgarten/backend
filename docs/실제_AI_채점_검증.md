## 입력 사례

- **두 영역 충족** — 11월 28일 확정 선적과 지연 사유를 정확히 안내했고, 학습자가 AI 초안을 일정표·계약서와 대조해 수정했습니다.
- **실무 과제 해결만 충족** — 같은 정확한 회신을 제출했습니다. AI 대화나 답안 수정 이력은 비워 두었습니다.
- **AI 활용만 충족** — 자료 대조와 초안 수정 기록이 있습니다. 최종 답안은 미확정인 11월 25일을 확정이라고 잘못 안내했습니다.
- **AI 대화 후 원자료를 검증하지 않음** — AI에게 초안을 요청해 받은 답변을 그대로 저장했습니다. 학습자가 AI 답변을 원자료와 대조한 기록은 없습니다.

## 검증 중 보완한 내용

- 채점 응답을 JSON Schema로 제한했습니다. 자유 형식 JSON 사용 시 발생한 출력 잘림과 파싱 실패를 재현한 뒤 수정했습니다.
- 최종 제출물과 원자료를 받는 결과물 채점, 대화와 수정 이력을 받는 과정 채점을 분리했습니다. 좋은 초안이 남아 있어도 최종 제출물에 잘못된 날짜가 있으면 결과물에 반영됩니다.
- 근거 ID의 후보를 해당 응시의 기록으로 제한했습니다. AI가 답변한 뒤 학습자가 남긴 대화나 독립적인 수정 기록을 확인할 수 없으면 검증은 0점으로 처리합니다. 점수 배점과 합격선은 기존 기준을 그대로 적용합니다.
