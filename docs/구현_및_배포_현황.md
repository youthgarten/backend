# 구현 및 배포 현황

2026년 11월 23일 KST 기준

무역 사무 학습자가 Phaser 강의실에서 영상을 보고, 시험장에서 바이어에게 보낼 영문 회신을 작성하는 과정이 운영 사이트에서 동작합니다. 평가는 실무 과제 해결과 AI 활용 역량을 함께 봅니다. [운영 사이트](https://youthgarten.vercel.app)

## 구현 범위

| 기능 | 현재 동작 |
| --- | --- |
| 로그인과 심사용 계정 | 로그인 및 세션 갱신을 지원합니다. 심사용 백엔드는 미리 발급된 계정으로 운영하며 공개 회원가입 API는 `404`를 반환합니다. 운영 화면에 회원가입 버튼이 표시됩니다. |
| Phaser 맵 | 광장·강의실·시험장을 오갈 수 있습니다. WebSocket으로 다른 접속자의 위치를 `x/y` 픽셀 좌표와 이동 방향으로 공유합니다. |
| 강의 및 수강 판정 | 무역 사무 강의 「AI로 납기 지연 회신 작성하기」의 영상 길이는 697초입니다. YouTube 영상과 동일 영상의 MP4 재생을 지원합니다. 중복 시청 구간을 제외하고 558초 이상 시청하면 시험에 응시할 수 있습니다. |
| 실무 시험 | 「바이어 납기 지연 항의 메일 회신」 과제에서 바이어 메일, 계약서, 선적 일정표를 열람합니다. AI 대화와 답안 수정 기록이 제출 및 채점에 쓰입니다. |
| 실제 채점 | 심사용 서버는 Codex CLI를 호출합니다. 실무 과제 해결과 AI 활용 역량은 각각 50점 만점에 최소 40점입니다. 확정 선적일 안내 필수 요건과 AI 답변 검증 최소 12점까지 충족해야 통과합니다. 채점 기록의 모델 식별자는 `codex-cli-default`입니다. |

## 배포 구성

| 구성 | 현재 상태 |
| --- | --- |
| 프론트엔드 | `youthgarten/frontend`의 `main`에 프론트 PR #21이 병합됐습니다. 병합 커밋은 `babdfed`이며 운영 빌드에 공개 WebSocket 대상이 포함된 것을 확인했습니다. |
| 심사용 백엔드 | Windows 호스트에서 FastAPI와 MySQL `8.0.46`을 실행합니다. 수강·시험 데이터는 별도 심사용 DB에 두고, Tailscale Funnel은 FastAPI의 로컬 포트 `8018`을 공개 HTTPS로 연결합니다. |
| REST 연결 | 브라우저는 운영 사이트의 `/api/v1/*`를 호출합니다. Vercel의 `vercel.json`이 Tailscale Funnel 공개 주소로 요청을 전달합니다. |
| 실시간 연결 | Phaser는 `VITE_PUBLIC_BACKEND_ORIGIN`으로 정해진 공개 백엔드에 `wss://`로 직접 연결합니다. 백엔드는 `https://youthgarten.vercel.app` 출처를 허용합니다. |
| 백엔드 Git 기준 | 심사용 서버에 배포한 소스는 백엔드 PR #3의 `d2da958`입니다. 백엔드 `main`의 애플리케이션 기준은 `6729f84`이며 PR #3은 병합 대기입니다. 심사용 시작 설정과 공개 가입 제한은 호스트에 적용돼 있습니다. |

Funnel 공개 주소가 바뀌면 프론트 `vercel.json`의 REST 대상과 Vercel Production의 `VITE_PUBLIC_BACKEND_ORIGIN`을 함께 갱신하고 다시 빌드·배포합니다. 심사 중에는 Windows 호스트, 백엔드 실행 창, MySQL, Tailscale Funnel이 실행 중이어야 합니다.

## 검증 결과

- Vercel 운영 사이트에서 심사용 계정 5개의 로그인과 수강률 0%인 강의 목록을 확인했습니다.
- 운영 브라우저에서 영상을 0%부터 1배속으로 시청했습니다. 80%를 넘겨 시험장에 입장했고 DB에 시청 597초가 기록됐습니다.
- 운영 브라우저를 공개 DNS 경로로 연결했을 때 재연결 안내가 사라졌고, 별도 접속자가 해당 브라우저의 `x/y` 좌표를 받았습니다. 검증 후 호스트의 Tailscale DNS 설정을 원복했습니다.
- 운영 브라우저에서 실제 Codex에 회신 초안을 요청하고 원자료와 대조한 뒤 수정본을 제출했습니다. **실무 과제 해결 50점, AI 활용 역량 50점, 총 100점으로 통과**했습니다.
- 별도 Funnel API 검증에서 동일한 회신을 AI 사용 기록 없이 제출했을 때 실무 과제 해결 50점, AI 활용 역량 0점으로 미통과했습니다.
- 현황 기록 시 운영 사이트의 `/api/v1/jobs`와 심사용 백엔드의 `/health/grading`은 `200`을 반환했습니다.

## 심사 운영 시 확인할 점

- 서버 창에서 텍스트를 선택한 상태에서는 응답이 멈춘 사례가 있었습니다. 창 제목에 `선택`이 표시되면 `Esc`로 선택을 해제하고 `/health/ready`와 `/health/grading`을 확인합니다.
- 배포 호스트 자체의 Tailscale 내부 DNS 조회 결과와 외부 접속자의 공개 DNS 조회 결과는 다를 수 있습니다. 운영 WebSocket은 공개 DNS 경로에서 확인합니다.
- 심사용 계정 정보는 별도로 전달합니다.
